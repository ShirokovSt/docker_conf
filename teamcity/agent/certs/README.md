# Свои сертификаты для агентов

Положите сюда корневые (и промежуточные) сертификаты в формате PEM с расширением `.crt` — например, свой CA, если сборкам нужен HTTPS к серверу с таким сертификатом.

При сборке образа агента (`teamcity\build-image.bat`) каждый `*.crt` попадает:
- в системное хранилище Ubuntu (git, curl, docker CLI);
- в `cacerts` всех JDK агента: 8, 11, 17, 21.

Сертификаты добавляются только в **новый** образ: положили файл — соберите образ под новым тегом и переключите на него агентов (см. [../../README.md](../../README.md#образ-агента)).

Пустая папка — сертификаты не добавляются. Содержимое папки, кроме этого файла, в git не попадает.
