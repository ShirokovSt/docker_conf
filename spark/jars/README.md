# Свои jar для Spark

Все `*.jar` из этой папки при старте попадают в classpath Spark (внутри контейнера папка видна как `/opt/spark/extra-jars`). Сюда кладутся зависимости, которые должны быть на сервере Spark заранее: драйверы JDBC, коннекторы, библиотеки для UDF и т.п.

- После добавления или замены jar: `docker compose restart spark` (или `spark\stop.bat` + `spark\start.bat`).
- Версии jar должны подходить к Spark 3.5.2 / Scala 2.12.

Содержимое папки, кроме этого файла, в git не попадает.
